# Практика C#



Проект содержит выполненные практические задания по C#.



## Описание



В данном репозитории хранятся исходные коды практических заданий.



## Git



Проект находится под контролем версий Git.



Ветка main: основная версия проекта.

Ветка main: обновлённая основная версия проекта.
Ветка feature: версия для демонстрации конфликта.

## Работа с Git

В проекте используются следующие правила:

- Основная ветка: main.
- Для новых заданий создаются отдельные feature-ветки.
- Сообщения коммитов оформляются по Conventional Commits.
- Перед объединением изменений создаётся Pull Request.
- Временные файлы Visual Studio и результаты сборки игнорируются через .gitignore.
